    Comment le classement est calculé

    Coût total = le plein + le carburant brûlé pour l'aller-retour depuis ton point de départ, avec ton véhicule. La distance est à vol d'oiseau multipliée par 1,3 pour approcher la route ; le cap indique la direction de la station. Les prix de plus de 14 jours et les ruptures signalées sont écartés.

    Les numéros reprennent le classement. Touche une station pour l'ouvrir.
