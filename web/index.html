      Comment le classement est calculé

      Coût total = le plein + le carburant brûlé pour l’aller-retour depuis ton point de départ, avec ton véhicule. La distance est à vol d’oiseau multipliée par 1,3 pour approcher la route. Les prix de plus de 14 jours et les ruptures signalées sont écartés. Positions et noms des stations : © contributeurs OpenStreetMap.

      Les numéros reprennent le classement. Touche une pastille pour ouvrir la station.
